# תמונות הסצנה

| קובץ | שימוש | הערות |
| --- | --- | --- |
| `avatar.png` | אווטאר עגול ב‑header וב‑empty‑state של הצ׳אט | מומלץ ריבועי/עגול, ~256×256 |
| `character.png` | דמות מלאה שנשענת על חלונית הצ׳אט בסצנת הדסקטופ (`/`) | דמות מצד שמאל; אזור ימין נחתך במסגרת `overflow-hidden`. שקיפות ברקע |
| `desktop.png` | רקע מלא של סצנת הדסקטופ | צילום מסך הפורטל; מוצג `background-size: cover`, `background-position: top` |

## החלפה

שמרו קובץ חדש באותו שם, או עדכנו את הנתיב ב‑`src/app/chat/chat-assets.ts`.
אם `character.png` החדשה בפרופורציות שונות – כווננו ב‑`src/app/desktop-scene/desktop-scene.component.ts`
את מסגרת החיתוך והמיקום: `w-[176px]` / `xl:w-[240px]` (רוחב חשוף), `h-[454px]` / `xl:h-[620px]`
(גובה), ו‑`start-[336px]` (מרחק מקצה הצ׳אט – כמה הדמות "נכנסת" מתחת לחלונית).
